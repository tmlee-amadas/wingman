# MVP 기능 명세 (대시보드 v1)

> 작성: 이태민(PM) 요청 · Claude 초안. 확정 기준은 메인 기획서 §7. 본 명세는 §7 범위를 일부 확장(인스타 자동 업로드)한 결정을 반영함.

## 1. 대시보드 화면 구성 (상단 → 하단)

1. **상단 바** — 인스타 연동 상태 표시 / 매장 위치 기반 날씨 위젯
2. **매출 현황 표** — 오늘·기간 매출과 SKU별 판매 현황 한눈에
3. **매출·수요 예측 차트** — 품목별·시간대별 다음날·다음주 수요 예측, 한산 시간대 표시 (제품의 핵심)
4. **이상감지 알림 영역** — 같은 요일·시각 평균 대비 이상 품목 표시
5. **오늘의 발주 추천 카드** — 한 줄 추천
6. **마케팅 액션 카드** — 할인 문구 생성 + 톤 설정 + 할인률 결정 모드 + 출력(인스타 게시, A4 팝카드 생성)

## 1-1. 사장님이 설정하는 것 (대시보드 컨트롤 3종)

1. **자동화 수준** — "AI가 전부 알아서 실행" vs "사람이 검토·승인 후 실행".
2. **콘텐츠 톤** — 친근/정중/유머 등 문구·팝카드 제작 톤.
3. **할인률 결정** — "AI가 알아서 할인폭 결정" vs "사장님이 정해둔 할인률 사용".

## 2. 기능 명세 (요약)

| # | 기능 | MVP |
| --- | --- | --- |
| 1 | 매출 현황 표 (sales_log 기반 오늘·기간 매출, SKU별 판매량) | 포함 |
| 2 | 발주 추천 한 줄 (newsvendor 기반) | 포함 |
| 3 | 이상감지 알림 (같은 요일·시각 평균 대비) | 포함 |
| 4 | 할인 문구 자동 생성 (SNS·문자) | 포함 |
| 5 | 콘텐츠 톤 설정 | 포함(신규) |
| 6 | 인스타 연동 상태 표시 | 포함(확장) |
| 7 | 인스타 게시 + 발송 모드 토글 (자동 발송 / 검토 후 게시) | 포함(확장) |
| 8 | 매장 위치 기반 날씨 | 보조(신규) |
| 9 | 할인률 결정 모드 토글 (AI 자동 / 사전 설정) | 포함(신규) |
| 10 | A4 팝카드 자동 생성 (PDF/이미지 → 출력) | 포함(신규) |
| 11 | 매출·수요 예측 (외부변수 연계, 단순 모델) | 포함(핵심) |
| 12 | 한산 시간대 예측 → 타이밍 트리거 | 포함 |
| 13 | 예측 vs 실제 정확도 → 재학습 입력 | 포함 |

## 3~5. 결정 사항 요약
- 인스타 자동 업로드를 MVP 핵심으로 승격(권한·비용 블로커는 과제로 남김).
- 마케팅 출력 채널: MVP는 **A4 팝카드 생성까지** 우선 진행.
- 미해결: 토글 기본값, 톤 옵션 확정, 날씨 위젯 v1 포함 여부.
