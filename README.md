# SyncDemand 대시보드 (창업캠프MCP)

베이커리 오븐(망원동)용 **수요예측 연동 마케팅 자동화 플랫폼** 대시보드 MVP.
Claude Design 프로토타입 `창업캠프MCP.dc.html`를 실행 가능한 단일 HTML 앱으로 구현했다.

- 원본 디자인: https://claude.ai/design/p/5393632e-7f65-41cd-988c-a1a8a4f1ca6b
- 구현체: [`index.html`](index.html) — 의존성 없는 standalone. 더블클릭으로 바로 열림.

## 실행

```powershell
# 가장 간단: 파일 더블클릭
start "index.html"

# 또는 로컬 서버 (인쇄/폰트 안정적)
python -m http.server 4599 --directory .
# → http://localhost:4599
```

## 화면 (사이드바 3개 뷰)

| 뷰 | 구현 내용 |
| --- | --- |
| **매출 현황** | KPI 6종 + SKU별 판매 표. `오늘 / 주간 / 월간` 토글이 KPI·표·합계를 실제로 재계산(주간 ×6, 월간 ×26). 과잉/이상 품목 행 강조, 시간대별 스파크라인. |
| **인스타 게시물 만들기** | 10종 설정 드롭다운 + AI 캡션 생성. 말투(정중/친근/유머/감성/간결)·주제 빵·할인율·시간을 바꾸면 캡션이 한국어 **조사(이/가, (으)로)** 받침까지 맞춰 자동 생성. 글자수 카운터, 이미지 다시 만들기, 게시(데모) 토스트. |
| **A4 팝카드 만들기** | 8종 설정 + A4 미리보기 라이브 바인딩. 헤드라인·서브카피 즉시 반영, 색상 테마 5종(악센트·종이색), 용지 방향(세로/가로/A5), 강조 배지 on/off. **PDF 다운로드 = 브라우저 인쇄(팝카드만 인쇄되도록 print CSS 격리)**. |

## 원본 대비 구현 메모

- 원본 `.dc.html`은 Claude Design 전용 런타임(`support.js` + 주입형 React)에 의존해 단독 실행 불가 → 동일 디자인을 vanilla JS로 1:1 재현하고, 프로토타입이 미완으로 남긴 탭 전환 로직(`state.tab` → 뷰 표시/숨김)을 완성.
- 표·KPI는 정적 마크업이 아니라 데이터 기반 렌더 → 기간 토글이 실제로 동작.
- 외부 발신은 모두 **데모(토스트)** 처리. 실제 인스타 게시·결제·POS 쓰기는 권한·비용 이슈로 범위 밖(원본 MVP 명세 §3과 동일 입장).
